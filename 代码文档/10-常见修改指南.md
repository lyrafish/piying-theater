# 10 · 常见修改指南（Recipe 手册）

> 这一篇是**干活用的**。每条配方都是：想改什么 → 改哪个文件哪一处 → 注意什么 → **可以直接贴给 Trae 的一句话**。
>
> 贴给 AI 时建议一次只做一条，做完刷新看一眼再下一条。

## A · 文案与内容

### A1. 改封面标题

**改**：`index.html` → `<h1 class="cover-title" id="coverTitle">皮影剧场</h1>`

**注意**：标题会被自动拆成单字做入场动画，字数变化不需要改 JS；
但超过 5 个字要同步调 `css/style.css` 的 `.cover-title { font-size }`，否则会换行。

> 「把封面标题改成『灯影千年』，如果超过 4 个字，同步调小 .cover-title 的字号，保持一行不换行。」

### A2. 改某段剧目的简介

**改**：`js/data.js` → 对应 `STORIES[i]` 的 `intro`

**注意**：约 100 字最佳。右栏宽度是 `clamp(11rem, 25vmin, 20rem)`，太长会出现滚动条（可以接受，但不好看）。

> 「把《梁祝》的 intro 改写得更口语一点，控制在 90 字以内，保持现在的文学腔调。」

### A3. 加一段经典剧目

**改**：`js/data.js` 的 `STORIES` 数组追加一条（字段见 `04` 文档）；
布景图放 `assets/stories/<剧目名>.jpg`；角色必须已存在于 `rig.json`。

**注意**：`chars` 只能 1~3 个（站位只支持三种）。

> 「在 STORIES 里加一段《白蛇传》，两个角色白素贞和许仙，布景 assets/stories/白蛇传.jpg，简介 100 字左右，notes 两条各 8-12 字。注意这两个角色 rig.json 里还没有，先不要动第四幕，我会另外处理素材。」

### A4. 改自定义人物的显示名

**改**：`js/data.js` 的 `CUSTOM_CHARS[].name`（纯文案，随便改）

**注意**：`id` 和 `file` **不能动**，它们要和 `rig.json` 对得上。

### A5. 让第二幕卡片的文案换行位置不同

**改**：`index.html` 里 `<div class="desc">` 内的 `<br>`

## B · 配色与字体

### B1. 换主色（朱砂 → 别的颜色）

**改**：`css/style.css` `:root` 的 `--cinnabar` / `--cinnabar-l` / `--vermilion`；
**同时**改 `js/stage.js` 的 `rgba(190,46,40,.72)`（提线）和 `#d9604f`（线头点），
以及 `js/hand.js` 的 `rgba(214,96,79,.75)` / `#e2564a`（小窗指尖）。

**注意**：Canvas 绘制的颜色**吃不到 CSS 变量**，这是全项目最容易漏的地方。

> 「把主色从朱砂 #a5302a 换成靛蓝 #2a4a6b。CSS 变量之外，还要改 stage.js 的提线颜色和 hand.js 的指尖颜色，把所有硬编码的红色 rgba 都列出来一起改。」

### B2. 换标题字体

**改**：新 woff2 放 `vendor/fonts/` → 改 `css/fonts.css` 的 `src` → 改 `:root` 的 `--f-title`

**注意**：新字体如果没有子集化，文件可能几 MB，首屏会明显变慢。

### B3. 让整体更"暖"/更"冷"

**改**：`css/style.css` 的 `--paper*`（宣纸色系）与 `--gold*`（描金）。
另外 `js/puppet.js` 的片元着色器里 `vec3 warm = vec3(1.07, 0.98, 0.85);` 控制影人本身的暖色。

### B4. 改按钮样式

**改**：`css/style.css` 的 `.btn`（朱砂实心）与 `.btn-ghost`（描边）。
hover 上浮效果在 `.btn:hover { transform: translateY(-.18rem) }`。

## C · 布局与自适应

### C1. 整体字号偏小/偏大

**改**：`css/style.css` 的 `html { font-size: clamp(11px, .62vmin + .62vw, 34px) }`

| 想要 | 改法 |
| --- | --- |
| 整体变大 | 三个值都调大，或把 `.62` 提到 `.70` |
| 大屏不再放大 | 上限 `34px` 调小 |
| 小屏不再缩小 | 下限 `11px` 调大 |

**注意**：改这个等于改全站比例，改完要逐幕看一遍。

### C2. 第二幕两张卡片的比例

**改**：`.gcard { aspect-ratio: 1.618 / 1 }`

### C3. 第三幕右栏太窄/太宽

**改**：`.side { flex: 0 0 clamp(11rem, 25vmin, 20rem) }`

### C4. 竖屏下的布局

**改**：文件末尾的 `@media (max-aspect-ratio: 1/1)` 块。
**不要新开断点**——全站只有两处媒体查询，是刻意的。

### C5. 第四幕两个影人大小/间距

**改**：`js/stage.js` 的 `_layout()`：

```js
let h = H * 0.70;          // 大小
const maxW = W * 0.335;    // 单人最大宽
const gap = W * 0.5;       // 间距
const bottom = H * 0.935;  // 脚底基线
```

> 「第四幕的影人太小了，把 _layout 里高度从 0.70 提到 0.80，同时把 maxW 从 0.335 提到 0.38，确保两人不会重叠。」

## D · 第三幕交互

### D1. 自定义剧目改成可以选 3 个人物

**改**：`js/main.js` 的 `if (state.selChars.length >= 2) state.selChars.shift();` → `>= 3`

**注意**：第四幕只画 2 个（`chars.slice(0, 2)`），第 3 个不会上台。
要真的上台需要改 `stage.js` 的 `_layout()` 与 `_applyHands()` 的分配逻辑——**属于大改**。

### D2. 人物卡片悬停时不预览，改成点击才预览

**改**：`js/main.js` `renderCustom()` 里删掉 `card.addEventListener('mouseenter', () => show(it));`

### D3. 改「进入」按钮的启用条件

**改**：`const ready = state.selChars.length > 0 && !!state.selBg;`
改成 `=== 2` 就是"必须选满两个人物"。

### D4. 翻幕太灵敏/太迟钝

**改**：`js/main.js` 的 `wheelNav()`：`if (now - lock < 780 || Math.abs(dy) < 4) return;`
以及触摸的 `Math.abs(dy) < 56`。
**改动画时长要同步改 `780`**（CSS 是 `.8s`）。

## E · 第四幕手感（最常调）

> 所有手感参数都在 `js/stage.js` 的 `_applyHands()` 里，详细解释见 `07` 文档第十节。

### E1. 影人动作幅度太小

**改**：`const gain = 2.35;` → 3.2 左右

**注意**：调太大会撞到 `const r = 0.34 * p.H` 的限幅，表现为"手指还在动但影人不动了"。
真要更大幅度，两个一起调。

> 「手势带动影人的幅度不够，把 _applyHands 里的 gain 从 2.35 调到 3.2，同时把控制点限幅半径 r 从 0.34H 提到 0.40H。改完告诉我这两个值分别影响什么。」

### E2. 影人抖动

**改**：`const dead = 0.006;` → 0.010

**注意**：死区太大会让"小幅度手指动作"完全无响应，0.012 以上会明显发木。

### E3. 影人反应慢半拍

**改**：`js/puppet.js` 的 `solve()`：`Math.pow(0.0009, dt)` → `Math.pow(0.0001, dt)`

### E4. 影人越玩越歪（零点漂移）

**改**：`_applyHands()` 里的回中逻辑：
```js
if (mag < 0.032 && p.calib > 30) { … * 0.012 }
```
把 `0.032` 放大（更容易触发回中）或把 `0.012` 调大到 `0.02`（回中更快）。

### E5. 换手指映射

**改**：`js/stage.js` 的 `FINGER_FOR`（只改这一个对象即可）

> 「把左右臂的控制手指对调：食指控右臂、中指控左臂。只改 FINGER_FOR，不要动其他逻辑。」

### E6. 鼠标操影的幅度/速度

**改**：`_virtualHand()` 里的 `const m = 0.62 + 0.5 * s;`（幅度）与 `Math.sin(T * 1.55 + ph[k])`（速度）

### E7. 不要鼠标操影

**改**：删掉 `_applyHands()` 里 `const virt = …` 及后续 `if (virt) { … }` 分支。
待机呼吸（`else` 分支）保留。

## F · 渲染视觉

### F1. 影人更亮/更暖

以及 `js/puppet.js` 片元着色器的 `vec3 warm = vec3(1.07, 0.98, 0.85);`

### F2. 影人半透明（像薄皮子）

**改**：`new Puppet(…, { alpha: 0.92 })`（当前没传，默认 1）

### F3. 提线更明显/更淡

**改**：`_drawFx()` 里 `ctx.strokeStyle = 'rgba(190,46,40,.72)'`（透明度）与 `ctx.lineWidth = Math.max(1, W / 1400)`（粗细）

### F4. 去掉落地投影

**改**：删掉 `_drawFx()` 里 `/* 落地投影 */` 那一段（从 `const gy` 到 `ctx.restore()`）

### F5. 顶部提线横杆位置

**改**：`_drawFx()` 的 `const barY = H * 0.028;`

### F6. 肢体弯折处有裂缝

**改**：`js/puppet.js` 的 `SIGMA` 数组，把对应骨的值调大 10~20%。
（索引对应：0躯干 1头 2左上臂 3左小臂 4右上臂 5右小臂 6左大腿 7左小腿 8右大腿 9右小腿）

### F7. 整个人像果冻一样软

**改**：`SIGMA[0]`（躯干）从 `0.60` 调到 `0.45`，或把四肢的 SIGMA 整体调小。

## H · 运行与部署

### H1. 换端口

**要改三处**：
1. `启动.bat` 的 `set PORT=8848`
2. `index.html` 的 `AUTO.port`（默认 8848）
3. `打开皮影剧场.url` 里的 URL

> 「把本地服务器端口从 8848 改成 9000，需要同步改 启动.bat、index.html 的 AUTO.port、打开皮影剧场.url 三处，注意 启动.bat 要存成 GBK + CRLF。」

### H2. 双击 index.html 后一直停在提示页

**排查顺序**：
1. 服务器是否在跑？（`启动.bat` 或 `python serve.py`）
2. 提示条上的地址是否与服务器端口一致？
3. 端口被占用但被别的程序占用 → 换端口

### H3. 部署到线上

**注意**：MediaPipe 的 WASM 需要正确的 `Content-Type: application/wasm`，
且建议开 `Cross-Origin-Opener-Policy` / `Cross-Origin-Embedder-Policy`。
纯静态托管（GitHub Pages / Vercel）通常没问题；某些 CDN 需要单独配置 `.wasm` 的 MIME。

### H4. 打包给别人

整个文件夹一起给即可（**`assets/` 和 `vendor/` 不能少**，共约 70MB）。
`.workbuddy-ai/`、`NewProject.1.toe`、`参考.mp4`、`预览图/`、`例图.jpg` 都可以不给。

## I · 性能

### I1. 第四幕掉帧

按顺序试：
1. `js/puppet.js` `_buildMesh()` 的 `W / 24` → `W / 32`（网格变粗）
2. `js/stage.js` `_resize()` 的 `Math.min(2, devicePixelRatio)` → `Math.min(1.5, …)`
3. `js/hand.js` 的摄像头分辨率 `640×480` → `480×360`
4. 删掉 `vendor/mediapipe/wasm/` 里 `nosimd` 两个文件（减少不必要的探测）

**改**：`js/main.js` `boot()` 的 `preload` 数组（减少预载项），
或把 `Promise.race` 的超时从 `6000` 降到 `3000`。

## K. 速查：文件 ↔ 症状

| 症状 | 先看哪 |
| --- | --- |
| 页面白屏 | `index.html` 的自检浮层 → 是否走了 file:// |
| 第三幕没有内容 | `main.js` `buildWorkspace()` 是否被调用（`state.mode` 为空） |
| 第四幕没有人 | `rig.json` 的 key 与 `data.js` 是否一致 |
| 第四幕人不完整/撕裂 | `data/rig.json` 的关节坐标（跑 `preview_rig.py`） |
| 手势没反应 | `hand.js` 的 `tracker.status` / `message` |
| 手势反了 | `stage.js` `_applyHands()` 的 `mirrorSign` |
| 字体方块 | `tools/build_fonts.py` 重新子集化 |
| 样式不生效 | 缓存（用 `serve.py`，它发 `no-store`） |
