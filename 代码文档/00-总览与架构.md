# 00 · 总览与架构

> 这份文档是「皮影剧场」的代码地图。目标是：**任何人（或 AI 编辑器如 Trae）读完这一份，就知道某个效果在哪一行、改哪一处、会牵连什么。**
>
> 各模块的逐行详解见同目录下 `01` ~ `10`。所有源码也可以双击 **`代码总览.html`** 在一个页面里通读。

---

## 一、这是什么

一个**纯前端、零依赖、完全离线**的四幕式国风网页：

| 幕 | 内容 | 核心文件 |
| --- | --- | --- |
| 第一幕 · 封面 | 宣纸底 + 毛笔标题逐字入场 + 「开始创作」 | `index.html` `css/style.css` |
| 第二幕 · 择幕 | 两张黄金比例卡片：经典剧目 / 自定义剧目 | `css/style.css` |
| 第三幕 · 剧目 | 顶部剧目 tab + 主舞台合成预览 + 右栏简介 + 戏箱 | `js/main.js` |
| 第四幕 · 演绎 | WebGL 蒙皮皮影 ×2，由双手五指实时提线 | `js/stage.js` `js/puppet.js` `js/hand.js` |

技术栈：**原生 ES Module + WebGL 1 + Canvas2D + MediaPipe Tasks Vision（本地分发）**。
没有框架、没有打包器、没有 CDN。改完文件刷新浏览器即可看到效果。

## 二、运行链路（从双击到出影）

```
浏览器请求 http://127.0.0.1:8848/
        │
        ├─ index.html
        │    ├─ <head> 内联自检脚本  ← 若为 file:// 会自动探测 8848 并跳转
        │    ├─ css/fonts.css        ← 5 个本地 woff2 艺术字
        │    ├─ css/style.css        ← 国风设计系统
        │    └─ <script type="module" src="js/main.js">
        │
        └─ js/main.js  ──────────────────────────────── 入口
             ├─ import data.js   → STORIES / CUSTOM_CHARS / CUSTOM_BGS / ROLES
             ├─ import stage.js  → class Stage
             ├─ fetch data/rig.json  → 20 个人物的骨骼坐标
             ├─ new Stage(els, rig)
             ├─ renderClassic(0) / renderCustom()   ← 第三幕 DOM 渲染
             └─ go(0)                                ← 停在第一幕
                        │
                        │ 用户翻到第四幕 go(3)
                        ▼
             Stage.enter(cfg)
             ├─ createGL(canvas)        → WebGL 上下文 + 着色器程序
             ├─ loadImage(角色png) ×2   → 生成 Puppet 实例（第二个 mirror=true）
             ├─ new HandTracker()       → getUserMedia + HandLandmarker
             └─ requestAnimationFrame(_loop)
                        │
                        ▼ 每帧
             Stage._loop()
             ├─ _applyHands()   → 手势 → 5 个控制点目标（含基准校准 / 死区 / 增益）
             ├─ Puppet.solve(dt) → 双骨 IK 解出 10 根骨骼的 3×3 仿射矩阵
             ├─ Puppet.draw()    → 顶点着色器做 LBS 蒙皮，一次性画完
             ├─ _drawFx()        → Canvas2D 画提线、落地投影、柔光
             └─ _drawHud()       → 摄像头小窗里的状态文字
```

## 四、模块依赖关系

```
                 ┌──────────────┐
                 │  data.js     │  纯数据，不 import 任何模块
                 └──────┬───────┘
                        │
  ┌──────────┐   ┌──────▼───────┐   ┌──────────────┐
  │ hand.js  │   │   main.js    │   │  stage.js    │
  │(MediaPipe)│  │  (入口/DOM)  │──▶│  (第四幕)     │
  └────┬─────┘   └──────┬───────┘   └───┬──────┬───┘
       │                │               │      │
       │                │        ┌──────▼──┐   │
       │                │        │puppet.js│   │
       │                │        │(WebGL)  │   │
       │                │        └─────────┘   │
       └────────────────┴──────────────────────┘
              stage.js 同时 import hand.js 与 puppet.js
```

**只有 `stage.js` 一个模块同时依赖另外两个运行模块。**
想换渲染方式 → 只动 `puppet.js`；想换捕捉方式 → 只动 `hand.js`；两者的接口都是固定的（见下）。

## 五、模块之间的「契约」

改代码时最容易踩的坑，就是改坏了下面这几处接口。

### 1. `puppet.js` 对外的接口

```js
new Puppet(gl, prog, loc, img, rig, { mirror, side, warm, alpha })
puppet.ctrl[key]        // 控制点目标，图像像素坐标；key ∈ head/handL/handR/footL/footR
puppet.ctrlRest[key]    // 静止位（只读基准）
puppet.bodyOff[2]       // 整体平移
puppet.bodySway         // 整体旋转（弧度）
puppet.solve(dt)        // 解算，必须每帧调用一次
puppet.draw(rect, canvasW, canvasH)
puppet.jointPos(key)    // 取关节当前屏幕位置（画提线用）
puppet.dispose()
```

### 2. `hand.js` 对外的接口

```js
new HandTracker({ video, canvas })
tracker.start()   // → Promise<boolean>   true = 摄像头+模型都就绪
tracker.stop()
tracker.hands     // [{ landmarks: [{x,y,z} ×21], label: 'Left'|'Right', score }]
tracker.status    // 'idle' | 'loading' | 'live' | 'error' | 'denied'
tracker.message   // 给用户看的中文提示
tracker.fps
TIPS = { thumb:4, index:8, middle:12, ring:16, pinky:20 }   // 指尖 landmark 索引
PALM = 9                                                    // 掌心 landmark 索引
```

### 3. `rig.json` 对外的结构

```jsonc
{ "chars": {
    "项羽": { "file": "assets/chars/项羽.png",
              "rig": { "root":[x,y], "neck":[x,y], "head":[x,y],
                       "shL":[x,y], "shR":[x,y], "elL":[x,y], "elR":[x,y],
                       "handL":[x,y], "handR":[x,y],
                       "hipL":[x,y], "hipR":[x,y], "knL":[x,y], "knR":[x,y],
                       "footL":[x,y], "footR":[x,y] } }
} }
```
坐标是**相对图片宽高的归一化值（0~1，y 向下）**，15 个关节缺一不可。

## 六、全局状态（`main.js` 的 `state`）

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `index` | 0~3 | 当前幕 |
| `mode` | `'classic'` / `'custom'` / `null` | 第二幕选的那条路 |
| `storyIndex` | 0~4 | 经典剧目选中第几段 |
| `tab` | `'char'` / `'bg'` | 自定义页当前分栏 |
| `selChars` | `[{id,name,file}]` | 已选人物，最多 2 个（先进先出） |
| `selBg` | `{id,name,file}` / `null` | 已选布景 |
| `rig` | Object | `data/rig.json` 解析结果 |
| `stage` | `Stage` | 第四幕实例，全局唯一 |

**第四幕只读不写这份 state**，`buildStageConfig()` 会把 state 快照成一份纯配置传进去。这是有意的：舞台不该知道第三幕怎么选的人。

## 七、可调参数的「旋钮总表」

调效果时 90% 的时间在动这几处。

| 想调什么 | 位置 | 参数 |
| --- | --- | --- |
| 整体主色 / 字体 / 圆角 | `css/style.css` `:root` | `--cinnabar` `--gold` `--f-title` … |
| 全站缩放基准 | `css/style.css` `html { font-size }` | `clamp(11px, .62vmin + .62vw, 34px)` |
| 两个影人的大小 / 间距 / 位置 | `js/stage.js` `_layout()` | `H*0.70` `W*0.335` `W*0.5` `H*0.935` |
| 手势带动影人的幅度 | `js/stage.js` `_applyHands()` | `gain = 2.35` |
| 手抖抑制 | 同上 | `dead = 0.006` |
| 控制点最大偏移 | 同上 | `const r = 0.34 * p.H` |
| 整体跟手（平移/摆动） | 同上 | `0.85` / `0.75` / `1.1` / `0.004` |
| 骨骼"肉"的软硬 | `js/puppet.js` `SIGMA` | 10 个比例值 |
| 蒙皮网格精度 | `js/puppet.js` `_buildMesh()` | `W/24`、`H/24`、上限 72×96 |
| 影人暖色 / 通透度 | `js/puppet.js` `draw()` → `u_warm` `u_alpha`；`stage.js` `warm: 0.40` | — |
| 提线颜色 / 粗细 | `js/stage.js` `_drawFx()` | `rgba(190,46,40,.72)`、`W/1400` |
| 摄像头分辨率 / 检测阈值 | `js/hand.js` `start()` | `640×480`、`0.5` ×3 |
| 手势跟随的平滑度 | `js/puppet.js` `solve()` | `Math.pow(0.0009, dt)` |

## 八、名词对照

| 词 | 在本项目里指什么 |
| --- | --- |
| **骨骼 / bone** | 10 根：躯干 + 头 + 左右上臂 + 左右小臂 + 左右大腿 + 左右小腿 |
| **关节 / joint** | `rig.json` 里的 15 个点：root/neck/head/shL/shR/elL/elR/handL/handR/hipL/hipR/knL/knR/footL/footR |
| **控制点 / ctrl** | 驱动用 5 个：`head` `handL` `handR` `footL` `footR`，对应五指 |
| **LBS** | 线性混合蒙皮：每个顶点按权重混合多根骨骼的变换，肢体转折处不会硬折 |
| **IK** | 反向动力学：给定末端目标点，用余弦定理反解肩/肘、髋/膝两段的角度 |
| **镜像 / mirror** | 右侧影人水平翻转，与左侧相对而立 |
| **基准校准 / base** | 以用户自然放松的手为"静止位"，只把手指的**相对变化**传给影人 |
| **提线 / fx** | Canvas2D 画在影人之上的朱红细线，视觉上像真的在提着皮影 |
