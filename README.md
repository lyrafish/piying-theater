# 皮影剧场

> 中国非物质文化遗产 · 皮影戏互动体验网页
> 以手为签，以影为戏 —— 可滑动浏览的四幕式国风网页项目

---

## 一、如何运行

浏览器出于安全限制，**摄像头与 WebAssembly 必须通过本地服务器访问**（直接双击 `index.html` 无法使用）。
任选一种方式启动：

| 方式 | 操作 |
| --- | --- |
| **Windows 一键启动（推荐）** | 双击 **`启动.bat`** —— 自动探测端口 / Python / Node，并打开浏览器 |
| 已启动过、只想再打开页面 | 双击 **`打开皮影剧场.url`** |
| Python | `python serve.py`（默认 8848 端口） |
| Node.js | `node serve.mjs`（默认 8848 端口） |
| VS Code | 安装 Live Server 插件 → 右键 `index.html` → Open with Live Server |

启动后浏览器会自动打开 `http://127.0.0.1:8848/`。
进入第四幕「演绎」时请点击浏览器弹出的**摄像头权限「允许」**。

### 打不开？看这里

**建议双击 `启动.bat`。** 如果你不小心双击了 `index.html`，浏览器会因 `file://` 协议禁用
ES Module / WASM / 摄像头而白屏 —— 此时页面会**自动探测本机 8848 端口的服务器**：

- 服务已在跑 → **自动跳转**到 `http://127.0.0.1:8848/`，无需手动改地址；
- 服务没跑 → 弹出提示浮层，写明"正在等待本地服务器…"，并**每 2 秒自动重试**。
  你此刻双击 `启动.bat`，这个页面会在 2 秒内自己跳过去，**不用刷新**。
  浮层上还有「立即重试」「直接打开」两个按钮，以及可一键复制的路径与命令。

| 现象 | 原因 / 处理 |
| --- | --- |
| 双击 `index.html` 出现提示浮层 | 走了 `file://` 协议 → 双击 `启动.bat`，页面会自动跳转 |
| 双击 `启动.bat` 一闪而过 | 脚本已自动提示未装 Python/Node；按窗口内指引安装其一 |
| 浏览器提示"端口被占用" | 脚本会自动检测：若 8848 已在服务，则直接打开页面 |
| 页面能开但第四幕无画面 | 未授权摄像头 → 允许权限；拒绝时会自动降级为**鼠标操影** |
| 改了代码刷新没变化 | 换端口/换服务器导致的缓存 → 用 `启动.bat`（它发 `no-store`），或 `Ctrl+F5` |

## 三、四幕结构

| 幕 | 内容 |
| --- | --- |
| **第一幕 · 封面** | 以 `页面背景` 为底，项目名「皮影剧场」毛笔艺术字 + 「开始创作」按钮 |
| **第二幕 · 择幕** | 同一背景，左右并列两个**黄金比例（1.618 : 1）等大**选择框：经典剧目 / 自定义剧目 |
| **第三幕 · 剧目** | 见下 |
| **第四幕 · 演绎** | 双影同台、十指提线的实时互动舞台 |

### 第三幕 · 经典剧目
顶部五栏 —— 霸王别姬 / 三打白骨精 / 新贵妃醉酒 / 梁祝 / 鹊桥相会。
点击任一栏，主舞台即时合成该剧的**布景 + 人物皮影**（下方「戏箱」列出该剧全部素材），
右栏显示**故事简介**，底部「进入」跳转第四幕。

### 第三幕 · 自定义剧目
顶部两栏 —— 人物 / 背景。
- **人物**：右栏可滚动列出 `自定义人物` 中的全部皮影，鼠标划过即在左侧放大展示；可择其二（左右手各领一影）。
- **背景**：右栏列出 `自定义背景` 中的全部布景，择其一。
- 人物与布景都选好后，「进入」点亮，跳转第四幕。

### 第四幕 · 演绎
- 左右两个皮影**镜像相对**，各由一只手实时操控；
- **五指提线**：拇指→头　食指→左臂　中指→右臂　无名指→左腿　小指→右腿；
- 摄像头画面以**小窗悬浮于左上角**，点击标题栏可**展开 / 收起**；小窗内含手部骨骼线框与运行状态 HUD；
- **「结束演绎」**位于右下角；
- 无摄像头（或未授权）时自动降级为**鼠标操影**，功能不中断。

## 五、技术实现要点

**素材预处理**（构建期完成，结果已存入 `assets/` 与 `data/rig.json`）
- 边界连通洪泛抠底：只移除与画面边缘相连、且与背景色相近的区域，因此皮影自身的黑色镂空轮廓与暗部纹样被完整保留；浅底浅色衣袍的人物采用收紧阈值，避免"吃掉"人物本体。
- 自动骨架提取：由剪影逐行分段求出躯干主轴，定位颈、肩、胯、分叉点，再取左右极值得到双手、底部左右簇得到双脚，输出归一化关节坐标。

**第四幕渲染 —— WebGL 蒙皮**
- 每个人物 10 根骨骼（躯干 / 头 / 左右上臂 / 左右小臂 / 左右大腿 / 左右小腿），静止姿态下按"点到骨段距离"的高斯核计算每个网格顶点的骨骼权重，顶点着色器做线性混合蒙皮（LBS），因此肢体运动是连续柔和的，不会出现硬接缝。
- 每个控制点用**双骨 IK** 反解：先把手部目标点变换进父级骨骼坐标系，再用余弦定理求肘 / 膝角度，得到自然的屈伸。
- 手指→关节：以**手掌中心为参照**，取"指尖相对掌心的向量"，并按用户**自然手型做基准校准**（进入后静置片刻即完成），因此放松的手对应影人的静止姿态，动手指才会牵动对应关节，长时间握持也不会漂移。

**手部捕捉**：MediaPipe HandLandmarker（VIDEO 模式，双手中），模型与 WASM 均随项目本地分发，不依赖 CDN。

**自适应**：根字号 `clamp(11px, 0.62vmin + 0.62vw, 34px)`，全站尺寸以 `rem` 表达，配合 `vmin/vw` 与 `aspect-ratio`，在 1280×800 至 4K 的各种屏幕比例下均等比协调；窄屏（竖屏）自动切换为上下分栏布局。
